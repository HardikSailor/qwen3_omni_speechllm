# MERaLiON-4 stage 1: mix `mv4_v0` and recipe `mv4_lora_v0` (2026-10-02)

First real fine-tune of Qwen3-Omni-30B-A3B for MERaLiON-4. Files: `mixes/mv4_v0.yaml` (generated by
`tools/make_mix_mv4_v0.py`), `configs/mv4_lora_v0.yaml`, `pbs/train_mv4_lora_v0.pbs`. Results:
`outputs/runs/mv4_lora_v0/` (with `omni_run/`: the exact config, mix, PBS script and command), W&B `i2r-llm/meralion_v4`,
group `mv4_lora_v0`.

## Goal (user)

Improve speech translation, spoken QA (incl. CPQA), speech summarisation, emotion understanding, and cultural understanding /
reasoning, while keeping ASR (a little ASR loss is acceptable if the other tasks improve). ASR data: Singapore languages incl.
Singlish (IMDA) and Southeast Asian languages; very little public English (LibriSpeech etc.). More than one stage is fine.

## Reference: MERaLiON-3 (multimodal_trainer)

| | MERaLiON-3 stage 1 (`meralion2_9b_gemma2_with_qa_and_caption_v4.14_part1`) | MERaLiON-4 stage 1 (this run) |
|---|---|---|
| Model | MERaLiON Whisper encoder (fully trained) + MLP adapter + Gemma-2 9B (LoRA) | Qwen3-Omni-30B-A3B thinker, all LoRA |
| LoRA | r64 / alpha 64 on the decoder | r64 / alpha 64: LLM attention (48 layers), audio encoder attention + MLP (32 layers), audio projector |
| LR / warmup | 5e-5, 200 steps (stage 2: 4e-5 on mix v4.14) | 1e-4 (LoRA only, no full-rank encoder), 500 steps, cosine to 1e-5 |
| Batch | 6 x 48 GPUs = 288 | 1 x 4 x 64 GPUs = 256 |
| Data | v4.7: ASR 99 sets (44 M per epoch), SQA ~550 sets, PQA, ST, SDS, CPQA, AC; 3 epochs | 148 sets, 4.74 M per epoch, 1 epoch (below) |
| Prompts | `random_multilingual`, `augment_prompt`, ASR normalisation off | same |
| Extra losses | language InfoNCE (0.05), logits entropy (0.2) | none (plain next-token loss) |

## Recipe `mv4_lora_v0`

See the comments in `configs/mv4_lora_v0.yaml`. One epoch = 18,500 steps x 256. Smoke test on 8 nodes (job 215260): 63.3 GiB
per GPU, ~3 s per step (~85 samples/s), eval works, checkpoint = adapter (101 M params, 404 MB fp32) + optimizer (809 MB);
no base-model weights are written. Expected time for the epoch ~16 h plus evals.

**Warmup bug found and fixed (job 215264):** `--warmup_steps` was silently set to 0 (ms-swift's `warmup_ratio: float = 0.` and
transformers 5.2's `__post_init__`, which copies any non-None `warmup_ratio` into `warmup_steps`). `train_omni.py` now passes
`--warmup_steps N` as `--warmup_ratio (N - 0.5) / max_steps`. Always confirm `warmup_steps` in `omni_effective.json`.

## Stage 2 (after evaluating stage 1)

See `docs/MERALION4_ROADMAP.md`. In short: evaluate every checkpoint per task and language against the base model; then a second
stage at a lower LR with more weight on the tasks that are still behind, new data for cultural knowledge and reasoning, and
ASR replay to hold ASR.
